# ThinkPixelTG documentation

This directory contains the durable architecture, security, contract, and
operational decisions for ThinkPixelTG. `PLAN.md` remains the implementation
contract and `TODO.md` remains the chronological delivery ledger.

## Layout

- `adr/` — consequential architecture decision records;
- `architecture/` — system context and domain design;
- `contracts/` — versioned internal and external interface contracts;
- `security/` — threat models, data handling, and security reviews;
- `operations/` — service levels, capacity, and runbooks.

Normative documents use the terms **MUST**, **MUST NOT**, **SHOULD**, and **MAY**
as defined by RFC 2119 and RFC 8174.
